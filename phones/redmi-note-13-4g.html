Is my Redmi Note 13 4G original?

Updated October 2026. Real specs from the sources below, and how to check a used Redmi Note 13 4G in about 10 minutes.

Short answer: A real Redmi Note 13 4G has the Qualcomm Snapdragon 685, 6 or 8 GB of RAM, 128 GB, 256 GB or 512 GB of storage, a 6.67-inch AMOLED screen (1080 x 2400, up to 120 Hz) and a 5000 mAh battery. Its model code is 23129RAA4G, 23129RA5FL, 23124RA7EO. A copy can show the right name, but it cannot change the processor, the real storage or the screen.

How to check a used Redmi Note 13 4G

  1. Read the model code. Open Settings, About phone, All specs, Model. It must say 23129RAA4G, 23129RA5FL, 23124RA7EO. Copies often copy this name too, so this is only the first check.
  2. Check the processor. It must be the Qualcomm Snapdragon 685. Copies run on a cheaper chip and sometimes rename it, so look at the number of cores and the graphics chip too. The Knowfone app does this for you and compares every part with this exact model.
  3. Do the black screen test. The real Redmi Note 13 4G has an AMOLED screen: open the black colour of the screen test in a dark room. It must be completely black. A grey glow means an LCD, which this model never had.
  4. Measure the refresh rate. Set Settings, Display to the highest refresh rate, then run the refresh rate test with a finger moving on the screen. The real phone reaches about 120 Hz.
  5. Prove the storage. Settings shows 128 GB, 256 GB or 512 GB on a real Redmi Note 13 4G. Copies can show any number; only writing data and reading it back proves the real size (how to check fake storage).
  6. Check the battery. The real battery holds 5000 mAh when new. See how to check battery health.
  7. Test the rest. Dial *#*#6484#*#* to open Xiaomi's hardware test menu (CIT) on most Redmi phones, or open Settings, About phone, All specs and tap Kernel version five times.

Questions

What processor does the Redmi Note 13 4G have?

The Redmi Note 13 4G uses the Qualcomm Snapdragon 685. A phone sold as a Redmi Note 13 4G with a different processor is not one.

How much RAM and storage does the Redmi Note 13 4G have?

The Redmi Note 13 4G comes with 6 or 8 GB of RAM and 128 GB, 256 GB or 512 GB of storage.

What is the model number of the Redmi Note 13 4G?

The Redmi Note 13 4G reports the model code 23129RAA4G, 23129RA5FL, 23124RA7EO. You find it in Settings, About phone, All specs, Model. Copies often copy this name too, so check the processor and storage as well.

Does the Redmi Note 13 4G have an AMOLED screen?

Yes. The Redmi Note 13 4G has a 6.67-inch AMOLED screen that runs at up to 120 Hz. In a dark room a black picture looks completely black on it.
