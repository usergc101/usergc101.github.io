Questions

Is the online phone test free?

Yes. All ten tests are free, need no account and run in the browser of the phone you are testing.

Does it work on an iPhone?

Most tests do. iPhones do not let web pages use the vibration motor or see the charger, so those two tests ask you to check by hand.

Is anything uploaded?

No. The camera picture, the sound and the results stay on the phone. The site has no trackers or analytics.

Can a browser tell if a phone is a copy?

Only partly. A refresh rate that is lower than the model's, or fewer cameras, are hints. The real processor, memory, storage and security state need an app: the free Knowfone app for Android compares them with the model the phone claims to be.
