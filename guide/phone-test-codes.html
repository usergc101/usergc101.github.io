Phone test codes by brand

Updated October 2026. About 4 minutes to read.

Short answer: dial *#06# on any phone for the IMEI. For a hardware test: *#0*# on many Samsung phones, *#*#6484#*#* on Xiaomi, Redmi and POCO, *#899# on Oppo and Realme, *#*#2486#*#* on many Motorola phones. Most Tecno and Infinix models have no public test code; use an app.

Phone makers build hidden test menus for their factories and repair shops. Some can be opened from the Phone app. They are handy when you buy a used phone, but they differ by brand, model and software version.

How to use them

  1. Open the Phone app, where you dial numbers.
  2. Type the code. Most menus open as soon as you type the last character, without pressing call.
  3. If nothing happens, this model does not have that menu. That says nothing about whether the phone is original.
  4. Only look and run tests. Do not change settings in engineer menus.

On Xiaomi phones you can also open the CIT menu without a code: Settings, About phone, Detailed info and specs, then tap Kernel version several times.

A warning about codes from strangers

Codes that start with ** or *21* followed by a phone number forward your calls to that number. A "seller" or "agent" who asks you to dial such a code can take over your calls, including the calls that read out login codes. Only dial codes you understand.

What no code can tell you

  • Whether the phone is a copy. A copy runs its own test menu and passes it. Compare the real processor, memory and cameras with the model (see original or clone).
  • The real storage size. Only writing data proves it (see fake storage).
  • Battery wear, on most phones (see battery health).
  • Whether the phone is locked to someone's account, blocked or stolen. Ask for a factory reset in front of you and check the IMEI.

Questions

What code do I dial to test a phone before buying?

Dial *#06# on any phone to see the IMEI. For a hardware test, use the brand's code: *#0*# on many Samsung phones, *#*#6484#*#* on Xiaomi, Redmi and POCO, *#899# on Oppo and Realme, *#*#2486#*#* on many Motorola phones. Tecno and Infinix have no public test code on most models.

What is the touch screen test code for Samsung?

Dial *#0*# and tap Touch. Drag your finger over the grid; each box turns green when the screen feels it. Boxes that stay white are dead spots. Some models and carrier versions block the code.

Is there a test code for Tecno and Infinix phones?

Most recent Tecno, Infinix and itel models have no public test menu. *#06# shows the IMEI. To test the parts, use an app such as Knowfone, which runs the same tests without codes.

Are phone test codes safe?

Test menus are safe if you only look and tap the tests. Do not change settings in engineer menus, and never dial a code someone sends you that starts with ** or *21*: those can forward your calls to another number.
