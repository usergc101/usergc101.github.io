How to tell if an Android phone is original or a clone

Updated October 2026. About 5 minutes to read.

Clones are phones built to look like a famous model, often with the famous name written into their software. They are common in markets for used and cheap phones. The good news: what is inside a phone is hard to fake, and a few checks find most copies.

1. Do not trust Settings, About phone

The model name, the storage size and even the Android version shown in Settings are text. A copy can show "Galaxy S23 Ultra, 512 GB" while it has a slow budget processor and 32 GB inside.

2. Compare the processor and graphics chip

Look up the real model's processor (for example Exynos 2400 or Snapdragon 8 Gen 3) before you meet. Then read what the phone really has with an app that reads the hardware. A copy usually has a much older chip with fewer and slower cores and a different graphics chip.

3. Prove the storage size

Fake storage is the most common trick: the phone reports a big number, but data written past the real capacity is lost. Only writing data and reading it back proves the size.

4. Count the cameras that really work

Some copies have extra camera rings with no lens behind them. Open every camera in the camera app, or let an app open each one.

5. Ask the security chip

Modern Android phones have a security chip that can sign a statement about the phone's system, checked up to Google's root. A tampered or fake system cannot produce that signature.

6. Special case: "iPhones" that run Android

If a phone sold as an iPhone has the Google Play Store, Android settings or a back button in Android style, it is not an iPhone.

Questions

Can a clone phone show the right model name?

Yes. The model name in Settings is text the seller or the factory can change. Check the hardware instead: the processor, graphics chip, memory, storage and cameras must match the real model.

Does a clone iPhone run Android?

Many do. A real iPhone never has Google Play, Android settings or Android apps. If a phone sold as an iPhone opens the Play Store, it is not an iPhone.

How can an app tell what processor a phone really has?

Apps can read the processor cores, the graphics chip and the memory directly. Knowfone compares them with the model the phone claims to be and also asks the security chip for a signed answer checked up to Google's root.

Is a clone always a bad phone?

Not always, but it is worth much less than the model it imitates, it rarely gets updates, and it often has much smaller storage than it claims. Knowing what it really is lets you pay the right price or walk away.
